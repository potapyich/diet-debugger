# Документ требований к продукту: Diet Debugger

## Обзор

Diet Debugger — AI-приложение (веб MVP, нативный мобайл в v2), которое анализирует питание пользователя по фото еды и объясняет *почему* диета не работает — а не просто считает калории. Пользователь фотографирует еду; приложение распознаёт блюдо, считает калории и БЖУ, выдаёт инсайты и отслеживает поведенческие паттерны на уровне приёма пищи → дня → недели → месяца.

## Проблема

Пользователи, которые хотят похудеть или улучшить питание, сталкиваются с одной и той же проблемой:
- Не понимают, почему не худеют, хотя "едят нормально"
- Не хотят вручную считать каждую калорию
- Не видят собственных паттернов поведения
- Существующие инструменты дают цифры, но не объяснение

## Цели

1. Позволить пользователю логировать еду по фото с минимальным трением
2. Давать мгновенный, практичный фидбэк после каждого приёма пищи
3. Выявлять паттерны питания за день, неделю и месяц
4. Объяснять *почему* диета работает или не работает — а не просто сообщать цифры
5. Помогать замечать и ломать плохие паттерны до того, как они срывают прогресс (Pattern Breaker)
6. Поддержка нескольких языков; AI отвечает на выбранном пользователем языке

## Не входит в MVP

- Интеграция с Apple Health / фитнес-трекерами (v2+)
- Соцфункции (v2+)
- Нативные мобильные приложения (v2+)
- Вход через соцсети (v2+)
- Freemium / платный доступ (v2–v3; глубокий анализ станет платным)
- Идеальная точность подсчёта калорий
- Сложная геймификация
- Real-time отслеживание

## Пользовательские сценарии

### Основной флоу — приём пищи
- Пользователь открывает приложение и видит экран состояния дня
- Нажимает "+" и выбирает: сфотографировать, выбрать из галереи, или ввести текстом
- Приложение обрабатывает асинхронно (показывается лоадер); когда готово — показываются калории, БЖУ, ингредиенты и индикатор уверенности
- Если уверенность низкая: "Мы не уверены — проверь или сфоткай снова" с лучшим вариантом для редактирования
- Пользователь подтверждает или редактирует, затем сохраняет
- Любой сохранённый приём пищи можно редактировать позже; инсайты пересчитываются автоматически
- После сохранения — мгновенно показывается 1–2 инсайта по приёму пищи

### Аналитика
- В любое время можно открыть вкладку "День": итоги vs цель, список приёмов, инсайты дня
- При первом открытии вкладки "Неделя" или "Аналитика" инсайты генерируются по запросу (lazy); когда готово — появляется toast-уведомление (справа сверху, в стиле macOS)
- Вкладка "Неделя" включает календарную сетку с цветовой подсветкой дней (зелёный / жёлтый / красный)
- Месячная стратегия и рекомендации — во вкладке "Аналитика и рекомендации"

### Pattern Breaker
- Приложение отслеживает встроенные поведенческие паттерны; алерты появляются как toast-уведомления или карточки в ленте
- Пользователь может сообщить о своих привычках; приложение учится на истории со временем

### Профиль и онбординг
- Можно начать пользоваться сразу без профиля (только общий анализ еды)
- UI постоянно рекомендует заполнить профиль для персонализированных инсайтов
- Поля профиля: вес, рост, возраст, пол, цель (похудение / поддержание / набор), тип диеты, тон фидбэка (нейтральный / прямой / жёсткий), язык

### Авторизация
- MVP: email + пароль
- v2: вход через соцсети (Google, Apple)

## Технические требования

**Frontend:** React + Vite SPA (веб MVP)
**Backend:** ASP.NET Core REST API
**База данных:** PostgreSQL
**Хранилище:** локальное с абстракцией для будущего облака
**Авторизация:** email/пароль (JWT); соцсети в v2

**AI-пайплайн:**
- Все AI-интеграции за интерфейсами (модель можно менять)
- Level 1 — MealFeedbackAgent: синхронный, rule-based, в рамках запроса (цель <2с)
- Level 2 — DailySummaryAgent, WeeklyPatternAgent, MonthlyStrategyAgent: асинхронные, запускаются при первом открытии экрана (lazy) или по расписанию
- FoodVisionAgent: асинхронный; результат через поллинг или SSE
- Текстовый ввод: свободный текст → FoodVisionAgent (текстовый режим) → тот же флоу валидации что и у фото

**Фото:** только временные; постоянно хранятся только структурированные данные (калории, БЖУ, ингредиенты)

**Локализация:** дефолт — английский; язык выбирается пользователем; AI отвечает на выбранном языке

**Модель данных (основные сущности):**
- `Meal`: timestamp, calories, macros (Б/Ж/У), ingredients, portion_estimate, confidence_score, source (photo/text/manual)
- `DailySummary`: итоги, сравнение с целью, инсайты, generated_at
- `WeeklyReport`: паттерны, статусы дней для календаря, generated_at
- `User`: профиль, цели, известные привычки
- `PatternEvent`: type (positive/warning), pattern_key, triggered_at, acknowledged

## Навигация

Четыре основных вкладки:
1. **День** — список приёмов пищи + текущие итоги + инсайты дня
2. **Неделя** — недельная сводка + паттерны + календарная сетка (цветовая подсветка дней)
3. **Аналитика и рекомендации** — месячная стратегия + лента Pattern Breaker
4. **Профиль** — настройки, цели, тон фидбэка, язык

## Pattern Breaker — встроенные паттерны

**Негативные (предупреждения):**
- Переедание по выходным (Сб/Вс систематически выше нормы)
- Основная масса калорий после 19:00
- Срыв после нескольких "хороших" дней (эффект компенсации)
- Пятничный вечер — исторически рискованное время
- Пропуск завтрака → вечерняя компенсация

**Позитивные (подкрепление):**
- N дней подряд в дефиците (страйк)
- Впервые удержал дефицит целую неделю
- Белок в норме 3+ дня подряд
- Перестал есть после X — новая привычка формируется

Дополнительно: паттерны, сообщённые пользователем + обучение на истории.

## UX детали

**Главный экран (вкладка "День"):**
- Состояние дня: потреблённые калории / цель, кольца БЖУ
- Список приёмов пищи
- Кнопка "+" → bottom sheet: Сфотографировать | Выбрать из галереи | Ввести текстом
- Toast-уведомления (справа сверху, стиль macOS): инсайты готовы, алерты Pattern Breaker

**Флоу анализа приёма пищи:**
1. Загрузить фото или отправить текст
2. Асинхронная обработка → спиннер
3. Экран результата: список ингредиентов, калории, БЖУ, бейдж уверенности
4. При низкой уверенности: "Мы не уверены — проверь или сфоткай снова"
5. Пользователь редактирует при необходимости → Сохранить
6. После сохранения — мгновенный инсайт по приёму пищи

**Редактирование:** любой сохранённый приём пищи редактируем; инсайты дня инвалидируются и пересчитываются при следующем открытии.

**Календарь (вкладка "Неделя"):** сетка с цветовой подсветкой: зелёный (в норме) / жёлтый (близко) / красный (превышение).

## Монетизация

- MVP: полностью бесплатно
- v2–v3: глубокий LLM-анализ (недельные паттерны, месячная стратегия, рекомендации) — платный

## Метрики

- DAU, количество приёмов пищи в день
- Retention (D7, D30)
- Вовлечённость в инсайты
- Частота подтверждения алертов Pattern Breaker
- Стабильность дефицита

## Будущее (v2+)

- Интеграция с Apple Health

- Отслеживание активности
- Дневник веса
